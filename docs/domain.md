# 无人机运行领域约定

服务面向低空运行、机队运维和合规管理人员。时间字段统一使用带时区的 ISO 8601
字符串，位置、授权和设备事件应保留来源时间与接收时间，不能用展示层文字替代
结构化状态。

健康接口只表示进程存活，不代表任何飞行或审批业务已经完成。需要落盘的数据应
使用运行时配置指定的位置，测试不得依赖主机上的隐藏状态。

## 违规飞行案件后端补充约定

- **双时间口径**：证据 `collected_at` 是出具单位（景区公安、Remote ID 运营单位、
  现场执法）的采集时间，归一化为带时区 ISO 8601 但不改变语义；`received_at`
  是本机关接收时间，由服务器时钟固定，客户端不可指定。两者不得互相覆盖。
- **追加封存优先**：证据原件、保管链、审计日志、事实版本、程序决定一律只追加；
  更正通过作废标记、关联撤销、新版本、superseded 留痕完成，禁止物理删除或
  覆盖式修改。
- **程序不倒置**：决定作出时固定引用快照（规则 id、事实版本、证据集合）。
  补交材料只影响其后的新判断；溯源中晚于决定的材料标注 `never_basis=true`。
- **并发冲突必须显式暴露**：事实清单用 `based_on` 乐观锁，冲突返回 409 由人
  合并，禁止后写静默覆盖先写。
- **授权分离**：敏感身份（加密封存、逐案逐人授权）与可公开摘要（脱敏、单独
  权限）是两条独立通道；查看和下载原件必入审计。
- **连续性**：办案期限与待签收交接随 SQLite 持久化，进程重启后继续计算/签收；
  归档必须生成可复算的整体指纹清单。
