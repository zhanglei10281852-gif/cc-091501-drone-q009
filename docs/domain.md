# 无人机违规飞行案件领域约定

时间字段统一使用带时区的 ISO 8601 字符串，服务内部按毫秒 epoch 排序。证据必须同时保留
来源单位口径的采集时间与本系统口径的接收时间；不接受无时区时间，不能用展示层文字替代
结构化状态。健康接口只表示进程存活，不代表任何办案业务已经完成。

## 证据保管

- 入库时计算 SHA-256 并内容寻址落盘，固定来源、采集时间、接收时间、入库时间、初始保管人。
- 原文只追加、不覆盖；重复入库同一字节内容复用同一 blob，不产生第二份原件。
- 状态仅通过追加保管事件改变：ingest / transfer / receive / recall / void。
  作废是标记（status=void），元数据与哈希保留可查，仅停止原文下载；作废须填原因，
  待签收交接未完成不得作废。
- 移交后进入 in_transit，只有指定接收人可以签收，移交人可以召回；待签收状态落库，
  进程重启不丢失，期间原文不得下载。

## 案件时间轴与程序决定

- 事件只追加：create / link / supplement / unlink / procedure / close。
- 补交材料使用 supplement，错误关联撤销使用 unlink 且必须记录原因；二者都不删除历史事件。
- 程序决定（procedure）固化决定时点的依据快照：事实清单版本号与全部在链证据
  （ID + SHA-256 + 状态）。事后补交或撤链不回溯修改快照，支持按 as_of 时点回放。
- 结案后案件冻结，不得再关联、补证、改事实或作出新决定。

## 事实清单与认定结论

- 事实清单按版本只追加保存；提交须带 base_version，与服务端当前版本不一致返回 409，
  响应中给出当前版本与最后编辑人，任何一方的修改都不会被覆盖。
- 认定结论固定 rule_version、fact_version 与 evidence_ids；未显式指定规则版本时，
  固定作出结论当下有效的版本。事后发布的新规则版本不影响既有结论。
- 结论引用的证据必须在作出时点在链且未作废。

## 授权与审计

- 角色：investigator（办案）、auditor（审计）、public_viewer（公开查询）。
- 敏感身份字段仅 investigator/auditor 可见；public_viewer 只能读公开摘要，不能下载原文。
- 元数据查看、原文下载、保管链查看、列表查看及全部写操作均写审计日志，审计日志仅
  auditor 可查询。

需要落盘的数据使用运行时 DATA_DIR 指定的位置，测试不得依赖主机上的隐藏状态。
